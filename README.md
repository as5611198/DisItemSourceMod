# 媽！這是哪個模組做的！

把滑鼠移到物品上，就能看見它來自哪個模組、哪張大地圖，以及目前能辨識到的取得線索。

## 給玩家

需要先安裝鴨嘴獸的萬物百科；在背包、倉庫等原生物品提示出現時查看來源。
需要先安裝 [鴨嘴獸的萬物百科](https://steamcommunity.com/sharedfiles/filedetails/?id=3603670962)。

Steam Workshop：[訂閱「媽！這是哪個模組做的！」](https://steamcommunity.com/sharedfiles/filedetails/?id=3603671043)
